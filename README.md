# 👋 Hi, I'm The .Spyke!

<img width="100" height="100" alt="SpykeLogo" src="https://github.com/user-attachments/assets/fa1799f5-38d4-40af-982d-90d8495d207e" />

🇫🇷 French Esports Tools Developer & Full Stack Developer specialized in live production.

I build software and workflows that help esports tournaments run smoother, from small community events to large-scale competitive productions.

I started coding at 14yo in 2018 with **Batch** and **Python** (yes, Batch was my first programming language.. in the default white Windows Notepad... for an entire year. Somehow I survived). Since then, I moved through **JavaScript**, **Discord Bots**, **TypeScript**, **APIs**, **automation**, and **backend development** to create tools used in real esports environments. Along the way, I also earned a two-year **Network Engineering degree**, strengthening my knowledge of **networking**, **systems administration**, and **DevOps**.

Today, I work at **POG Group** as a **Lead Software Developer**, **Esports Observer**, and **Technical Director**, creating the technology behind our competitive broadcasts.

My goal is simple:
> Make esports production more accessible, automated, and higher quality — especially for smaller organizers who don't always have access to professional tooling.

I believe competitive gaming grows when everyone has better tools, better opportunities, and a more inclusive environment.

---

## 🎮 Esports × Development

I believe technology can help esports grow.

My work focuses on building tools that make productions More reliable, More automated, Easier to operate More accessible for smaller organizers.

Through my work at **POG Group**, I develop private production systems used in esports environments, including:
- Tournament APIs
- Live data ecosystems
- Overlay systems
- Custom production applications
- Automation workflows

Most of these projects are private, but they are built with real broadcasts and competitive events in mind.
